CSG BOOLEAN

Cuts/merges two meshes using Rust Wasm. Spawns a red sphere and green box that intersect.

WHAT THIS DOES
Sends both meshes' position/index arrays to compute_boolean in Rust Wasm. The returned Float32Array + Uint32Array is wrapped in a new BufferGeometry.

DECIMATE MESH

Reduces a high-poly torus knot to a target triangle percentage. Watch the wireframe density drop.

10%100%
WHAT THIS DOES
Calls decimate_mesh(positions, indices, percent) which keeps every Nth triangle, then rebuilds a compact vertex buffer. Result re-attached as a wireframe mesh so you can see the reduced edge count.

BVH BOUNDS

Computes the AABB of a mesh via Rust Wasm. The result is rendered as a neon-green wireframe around the source mesh.

WHAT THIS DOES
Calls generate_bvh(positions, indices) which streams all positions through chunks_exact(3) to find the min/max in each axis. The returned AABB is drawn as a THREE.Box3Helper.

PHYSICS STEP

Runs a semi-implicit Euler integration with gravity + ground collision in Rust Wasm. 50 colored cubes drop in real time.

WHAT THIS DOES
Each frame, packs all bodies into a JS array, sends to step_physics, applies gravity v.y -= 9.81 * dt, integrates position, and clamps to the ground plane. Result is split back to per-cube position/velocity.

POINT CLOUD

Parses a binary XYZ buffer via Go Wasm. We generate 5,000 random points in JS, hand the bytes to Go, and Go returns the parsed positions as a Float32Array.

WHAT THIS DOES
JS builds a packed binary buffer (3 little-endian float32s per point). Go's parsePointCloud copies bytes with js.CopyBytesToGo, decodes with binary.LittleEndian.Uint32 + math.Float32frombits, and returns positions/colors as Float32Arrays. Rendered as THREE.Points.

CAD IMPORT

Routes a CAD-shaped buffer through Go Wasm's importCAD. The placeholder parser returns a single cube mesh — enough to verify the bridge works end-to-end.

WHAT THIS DOES
Builds a mock STEP-shaped binary buffer in JS, hands it to importCAD, Go returns {meshes: [{positions, indices}]}. We rebuild each mesh with a distinct face color and group them as a THREE.Group.
